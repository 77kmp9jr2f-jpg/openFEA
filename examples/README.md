# Example studies

`print-coupon.stl` is a 40 × 10 × 8 mm closed box used to exercise STL import, surface selection, and the homogenized print model. In the workspace, **Use example print coupon** inspects it, meshes it, enables the print model, and pre-selects the X=0 / X=40 faces. Dimensions are demonstration inputs, not a measured printed coupon.
