# Example studies

`print-coupon.stl` is a 40 × 10 × 8 mm closed box used to exercise STL import, surface selection, and the homogenized print model. In the workspace, **Use example print coupon** inspects it, meshes it, enables the print model, and pre-selects the X=0 / X=40 faces. A copy is also served as `public/print-coupon.stl`.

Typical next steps: confirm the review checkbox, run on **Local CPU**, pin the result, raise infill, run again, read the comparison table. See [docs/PRINT-STL.md](../docs/PRINT-STL.md).

Dimensions are demonstration inputs, not a measured printed coupon.
